# Anonimizador de la Residencia

Aplicación para Windows desarrollada por la Residencia San Francisco y San Vicente de Manises. Ayuda a preparar copias de Word y PDF antes de compartirlos o subirlos a una herramienta de inteligencia artificial. El tratamiento se realiza en el equipo, sin conexión y sin IA.

## Descargas

- [Aplicación para Windows de 64 bits](https://github.com/residencia-dev/anonimizador-residencia/releases/latest/download/Anonimizador_Residencia.exe)
- [Manual de uso en PDF](https://github.com/residencia-dev/anonimizador-residencia/releases/latest/download/Manual_Anonimizador_Residencia.pdf)
- [Historial de versiones](https://github.com/residencia-dev/anonimizador-residencia/releases)

Para empezar, descarga la aplicación, ábrela en Windows y arrastra los documentos a la ventana. Puedes revisar las marcas, añadir términos al diccionario personal y guardar copias individuales o por lotes. En **Salida** puedes elegir el formato original o Markdown.

Abre y revisa la copia antes de compartirla. Las páginas escaneadas se pueden marcar con el ratón.
